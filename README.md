## About

**ResellNom** is a modern and user-friendly platform designed for reselling digital services. The project focuses on providing a clean interface, simple navigation, and an easy-to-use experience for both customers and resellers.

### Features

* 🛒 Simple and clean homepage
* 📦 Service/product management
* 👤 User-friendly dashboard
* 💳 Easy order and payment flow
* 📊 Order and service tracking
* 📱 Responsive design for mobile and desktop
* ⚡ Fast and lightweight interface

### Tech Stack

* HTML
* CSS
* JavaScript
* PHP / Backend integration

> This project is intended for educational and legitimate business use.
